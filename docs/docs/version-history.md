# Version History

This page is a historical reference for **ingot**'s past versions including the version number, what changed and classification.

## Notation

**ingot** follows standard semantic versioning (`x.x.x`) with a few additions. **ingot** versions are given extra tags when the commit does not affect library functionality or it is not ready for a full release yet. There are 4 tags, all followed by a number that counts the number of commits that qualify that tag:

- `-d` - Used to mark commits that affect **documentation** but do **not** affect the core library
- `-e` - Used to mark commits that are **external** to the library (e.g: changing `ingot.Example` does not affect `ingot.Core` in terms of functionality)
- `-a` - Used to mark commits to **accumulate**. As a general practice, I'd never publish more than one release of **ingot** per day, but in the event that happens, updates are accumulated until the next release
- `-s` - Used to mark commits that are **staging** commits (e.g: the first concrete part of an implementation so I can experiment with the rest locally). Similar to pre-releases

So a version with 2 consecutive documentation updates without a release would use the `-d2` tag. A documentation update followed by an accumulation would become `1.0.0-a1d2`

> [!NOTE]
> The tagging system is designed so that the repository version stays the same as the package version because tags are always dropped on the next release:
> `1.0.0-d1 -> 1.0.0-a1d2 -> 1.0.1`

### `1.2.0-s2` - `Either object for JSON loose typing`

**Classification:** `staging`

* add Either object for JSON serialisation that can be one of multiple types, e.g an Identifier or a BlockTypeDescriptor
* TraitGeneratorV2 now does not overwrite files if they do not have the autogenerated header at the top
* removed autogenerated header at the top of trait interfaces that have been modified outside of the generator with custom types - Either objects have been added temporarily until they are properly incorporated to resolve oneOf objects in the generator
