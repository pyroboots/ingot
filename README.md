# ingot

[![C#](https://img.shields.io/badge/C%23-239120?logo=csharp&logoColor=white)](https://learn.microsoft.com/dotnet/csharp/)
[![.NET](https://img.shields.io/badge/.NET-512BD4?logo=dotnet&logoColor=white)](https://dotnet.microsoft.com/)

**A C# framework to programmatically create Minecraft Bedrock Edition packs** - because writing mountains of JSON sucks.

## ✨ Features

- **Simple, Type Safe and Fluent API** - Define items, blocks, entities and more with clean C# code
- **Automatic Manifest Generation** - Both `manifest.json` files are created for you
- **Behaviour + Resource Pack Support** - Full control over BP and RP with easy linking
- **Script API Ready** - Built-in support for JavaScript scripting
- **Compile-Time Logging** - Clear feedback during pack generation
- **Extensible** - Easy to add your own generators and content types
